# LeetCode Problem Solutions

This repository contains solutions to popular LeetCode problems, implemented in Python. Each file corresponds to a specific problem and includes a clear, efficient solution.

## Contents
- `Countains_Duplicate.py`: Solution for checking if a list contains duplicates.
- `Encode_and_decode_strings.py`: Encode and decode a list of strings.
- `Group_Anagrams.py`: Group words that are anagrams.
- `longest_consecutive_sequence.py`: Find the longest consecutive sequence in an array.
- `Products of Array Except Self.py`: Product of array elements except self.
- `Top_K_Frequent_Elements.py`: Find the k most frequent elements.
- `Valid Sudoku.py`: Validate a Sudoku board.
- `valid_palindrome.py`: Check if a string is a valid palindrome.
- `neetcode.ipynb`: Jupyter notebook for notes and explanations.

## Usage
You can run any of the Python files directly to test the solutions. Each script is self-contained and can be executed with Python 3.
